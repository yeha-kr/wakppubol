# 왁뿌볼 만들기

플래시 쿠킹 게임 감성의 **왁뿌볼 제작 + ASMR 금내기** 모바일 웹 게임.
점토를 반죽하고, 왁스를 입히고, 고무와 케이블 타이로 감싼 뒤 — 왁스 껍질에 시원하게 금을 냅니다.

## 플레이

- 공개 URL: **https://GITHUB_ID.github.io/wakppubol/** (배포 후 갱신)
- 모바일 세로 화면 권장 (iOS Safari / Android Chrome). 첫 화면에서 "탭하여 시작"을 누르면 소리가 켜집니다.

## 조작법

| 단계 | 조작 |
|---|---|
| 1. 점토 반죽 | 점토 덩이를 잡고 **위로 뜯어** 볼에 2~3조각 담기 → 볼을 **문질러** 섞기 |
| 2. 왁스 코팅 | 공을 냄비에 담가 **1초 유지** → "이제 천천히 빼세요"가 뜨면 **천천히** 빼기 ×4겹 (빠르게 빼면 얼룩 실패) |
| 3. 고무 + 케이블 타이 | [고무 패팅 하기] 버튼 → 화면을 **아래로 스와이프**해 타이 조이기 (래칫 — 되돌아가지 않음) |
| 4. 왁뿌볼 금내기 | **탭 / 연타 / 길게 눌렀다 떼기(0.3초+)** 로 왁스에 금 내기. 12부위 전부 금이 가면 완성! |
